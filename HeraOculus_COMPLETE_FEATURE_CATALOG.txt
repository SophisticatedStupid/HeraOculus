3.1 Core Types (src/types/earthScience.ts)

  - DiagnosticResults: normality verdict (no_evidence_against |
    evidence_against | insufficient_data), autocorrelation (r0, r1,
    p_value) with null-safe access, observation ordering preservation

3.1a Scientific Interpretation Audit (frontend interpretation layer)
  - plainEnglishVerdict(): directional + magnitude + significance +
    uncertainty + limitations for trend verdicts
  - generateScientificImplication(): 26-variable hedged language layer
  - Avoids causal claims; uses "consistent with — but not proof of",
    "may reflect", "attribution requires additional analysis" phrasing
  - Removes definitive causal language ("caused by random seasonal
    fluctuations", "conclusively state", "prove significance")

6.1 Provenance

6.2 Auth
   - AuthStatusResponse: earthdata_configured, earthdata_source,
     earthdata_username_hint?, earthdata_token_hint?, firms_configured,
     firms_source, firms_key_hint?, keyless_feeds_available[]
   - HealthResponse: status, version, capabilities{}, auth
   - No AuthConfigRequest schema: credentials are server-managed only
   - /api/v1/auth/status is the sole auth endpoint (read-only)
   - /api/v1/auth/configure intentionally absent (404) — no per-user
     credential configuration to prevent cross-user contamination
   - /api/v1/health returns full auth status as part of health check

6.3 Time Series Input
  - TimeSeriesInputPoint: date, value?

6.4 SARIMA Request (SarimaRequest)
  - dates[] (min 24), values[] Optional<float> (min 24)
  - forecast_steps (1-60, default 12)
  - seasonal_period (1-24, default 12)

8. STATISTICAL ANALYSIS METHODS
================================================================================

8.1 Frontend Web Worker Methods (client-side)
  1. Bootstrap Confidence Intervals
     - Module: bootstrapCI
     - B >= 2000 iterations
     - Statistics: mean, median
     - Alpha configurable (default 0.05)

  2. Theil-Sen Estimator (Full Pairwise Slopes)
     - Module: senSlopeExact
     - O(n^2) exact pairwise slope computation
     - Robust to outliers

  3. Seasonal Mann-Kendall Trend Test
     - Module: seasonalMannKendall
     - Methods: standard, hamed_rao, tfpw
     - Autocorrelation correction
     - Season length configurable (default 12)

  4. PCA / SVD Decomposition
     - Module: pcaAnalysis
     - Principal Component Analysis
     - Data matrix input, optional labels

  5. Pettitt Change-Point Detection
     - Module: pettittChangePoint
     - Non-parametric change point detection
     - Optional dates input

  6. Descriptive Summary Statistics
     - Module: computeDescriptiveStats
     - Mean, median, std, min, max, quartiles, etc.

  7. Nonlinear Regression
     - Module: nonlinearRegression
     - Models: exponential, logarithmic, power, quadratic, logistic

  8. Generalized Extreme Value (GEV) Fit
     - Module: fitGEV
     - Block maxima approach
     - Configurable block size (default 12)

  9. One-Way ANOVA
     - Module: runOneWayAnova
     - Analysis of variance across groups

8.2 Backend Statistical Methods (server-side)
  1. SARIMA / ARIMA State-Space Forecasting
     - Service: forecast_service.py (run_sarima_forecast)
     - Library: statsmodels SARIMAX
     - Missing-gap support (NaN preserved in state-space)
     - Auto order selection via AIC (8 candidate models)
     - 95% and 80% prediction intervals
     - Holdout backtest (RMSE, MAE, MAPE)
     - Ljung-Box residual autocorrelation test
     - Shapiro-Wilk normality test
     - Seasonal decomposition (additive STL/classical)
     - Model candidate table (order, seasonal_order, AIC, BIC)

  2. Bayesian MCMC — Robust AR(1) Trend
     - Service: bayesian_service.py (_run_robust_ar1_mcmc)
     - Likelihood: Student-t (df=5) for robustness
     - Covariance: exact irregular-gap AR(1) (rho^dt scaling)
     - Covariates: linear trend + annual harmonic (sin/cos 2*pi*t)
     - Sampler: Adaptive Random-Walk Metropolis-within-Gibbs
     - Chains: 2-4 (default 3), draws 300-2500 (default 900),
       burn_in 150-1200 (default 450)
     - Diagnostics: split R-hat, ESS, mean acceptance rate
     - Outputs: slope/decade, intercept, sigma, AR(1) rho,
       Probability of Direction, posterior histogram, traces,
       predictive trend with 50%/95% envelopes

  3. Bayesian MCMC — Changepoint (Piecewise Hinge)
     - Service: bayesian_service.py (_run_changepoint_mcmc)
     - Model: Bayesian piecewise linear hinge regression
     - Parameters: intercept, pre-shift slope, slope change (delta),
       changepoint tau (bounded [0.12, 0.88] of series), sigma
     - Sampler: Adaptive Metropolis-within-Gibbs
     - Diagnostics: split R-hat on delta and tau, ESS
     - Outputs: pre_slope, post_slope, slope_shift, changepoint date/index,
       Probability of Direction (accelerating/decelerating),
       posterior histogram, traces, predictive trend envelopes

  4. Extreme Value Analysis — GEV Block Maxima
     - Service: extreme_service.py (mode: gev_block_maxima)
     - Distribution: Generalized Extreme Value (scipy genextreme)
     - Method: Block maxima, configurable block size
     - Adaptive chunking fallback for short series
     - Goodness of fit: Kolmogorov-Smirnov test
     - Family classification: Frechet (heavy-tailed) / Weibull (bounded) /
       Gumbel (light-tailed) based on shape xi
     - Empirical plotting positions: Gringorten
     - Return levels: configurable periods (default 2,5,10,20,50,100)
     - Bootstrap 95% CI for return levels (80 bootstrap samples)

  5. Extreme Value Analysis — GPD Peaks-Over-Threshold
     - Service: extreme_service.py (mode: gpd_pot)
     - Distribution: Generalized Pareto (scipy genpareto, floc=0)
     - Threshold: quantile-based (default 0.85, adaptive fallback 0.70)
     - Exceedance rate per year
     - Return levels with bootstrap 95% CI
     - Goodness of fit: Kolmogorov-Smirnov test

  6. Spatial False Discovery Rate (Spatial FDR)
     - Service: spatial_fdr_service.py (run_spatial_fdr_analysis)
     - Test: Vectorized per-cell Mann-Kendall (Wilks 2016 framework)
     - Grid: (T, H, W) spatio-temporal cube
     - Correction methods: Benjamini-Hochberg (BH), Benjamini-Yekutieli (BY),
       Holm, Bonferroni
     - Outputs: Z-scores, p-values, slopes/decade, q-values,
       raw vs FDR-significant cells, false positives pruned,
       % area significant, field significance, Wilks effective alpha,
       min p-value, min q-value, max/min slope
     - Visuals: base64 trend PNG + FDR mask PNG

  7. Vectorized Mann-Kendall Trend Test
     - Component of spatial_fdr_service.py
     - Pairwise sign-difference S statistic
     - Exact variance under no-ties
     - Z-score and two-sided p-value via normal approximation
     - OLS slope per decade with NaN-safe handling
     - Minimum 5 valid observations per cell required

13. KEY DESIGN PATTERNS
================================================================================

- Layered architecture: routers -> services -> external APIs/libraries
- Graceful degradation: live API -> keyless fallback -> synthetic demo
- Transparent provenance: every response includes tier, source_name,
  dataset_id, is_live, status_message
- Read-only credential store: auth_store resolves env vars once at process start
- Web Worker offloading: heavy stats on client-side worker with fallback
- Base64 PNG previews: raster spatial outputs embedded as data URIs
- Pydantic v2 schemas: validated request/response contracts
- NaN-safe computations: missing data handling throughout stats pipeline
